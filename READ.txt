HYPERSPECTRAL IMAGE COMPRESSION /LIFTING BASED DIRECTIONLET/TD WITH HOOI/HUFFMN CODING

The proposed compression framework consists of:

1. Lifting-based Directionlet Transform
2. Tucker decomposition using HOOI
3. Entropy coding using Huffman coding
5. Reconstruction and quality evaluation

## Dataset

The experiments were conducted using publicly available
hyperspectral image datasets.

## Requirements

- MATLAB R2024a or later
- Image Processing Toolbox
- Statistics and Machine Learning Toolbox
- Wavelet Toolbox

## How to Run

1. Download or clone this repository.
2. Add the MATLAB folder and subfolders to the MATLAB path.
3. Place the dataset in the specified dataset folder.
4. Run:mainPROGAM.m

## Evaluation Metrics

The program calculates:

- MSE
- PSNR
- Compression Ratio
- Bits Per Pixel Per Band (bpppb)
- Compression Time
